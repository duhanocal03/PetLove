## 📖 About

PetLove is a modern, responsive web application for browsing pets, reading adoption notices, saving favourites and managing user interactions. The application consumes the public GoIT PetLove API.

## Live Demo

> **App:** [https://pet-love-eosin.vercel.app/](https://pet-love-eosin.vercel.app/)

## ✨ Features

- Authentication UI
- Browse pet notices
- Search & filter pets
- Add / remove favourites
- Responsive design
- Redux Toolkit state management
- Axios API requests
- React Router navigation
- Form validation

## 🚀 Installation

```bash
git clone https://github.com/duhanocal03/PetLove.git
cd PetLove
npm install
```

## ▶️ Available Scripts

```bash
# Development
npm run dev

# Production build
npm run build

# Preview production build
npm run preview

# Lint project
npm run lint
```
